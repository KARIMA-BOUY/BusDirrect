BusDirect:

Application web de gestion des réservations de bus entre Safi et Marrakech.

 Fonctionnalités:

- Afficher les 20 sièges.
- Réserver un siège.
- Modifier une réservation.
- Supprimer une réservation.
- Rechercher un passager.
- Afficher les places disponibles et la recette totale.
- Sauvegarder les données avec `localStorage`.
- Déplacer un passager avec Drag & Drop.

Technologies:

- HTML
- Tailwind CSS
- JavaScript
- localStorage
